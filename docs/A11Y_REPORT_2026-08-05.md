## Fixes Applied

### 1. /demo.html — color-contrast (20 nodes, serious)

**Root cause:** `styles.css` rule `.article-body { background: var(--paper) }` (light #EBE8DD) was overriding `demo.css` rule `body { background: var(--demo-ground) }` (dark #10201A) due to specificity (class beats element). The demo page's light-on-dark text colors (designed for the dark background) were rendering against the light paper background, failing WCAG AA contrast on 20 nodes (kicker, h1, dek, proof-grid labels, buttons).

**Fix in `site/styles.css`:**
- Added `.article-body.demo-watch { background: #10201A; }` — higher-specificity (0,2,0) rule that restores the dark background for the demo-watch page.
- Added `.article-body.demo-watch .btn { color: #E8E3D4; border-color: rgba(232, 227, 212, .4); }` and hover state — ensures `.btn` text (which inherits dark `var(--ink)` from the base `.btn` rule) is light on the dark demo background.

**Verification:** Computed body background on /demo.html changed from `rgb(235, 232, 221)` (paper) to `rgb(16, 32, 26)` (demo-ground). All text/background combinations now pass 4.5:1.
