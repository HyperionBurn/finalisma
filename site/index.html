The problem

Pasted prompts. No record. No governance.

Right now, coordinating agents means pasting the same prompt into every window and hoping nothing drifts. No shared state, no ordered delivery, no evidence gate — just copy-paste and crossed fingers.

agent-instructions.md — pasted 5× 
You are agent-a. Read handoff.txt and continue the work.
Make sure you don't duplicate what agent-b did.
The scope is: the retry boundary in handoff.txt.
Report back when done. Do not claim tasks that aren't yours.
agent-a sees v1 agent-b sees v3 agent-c sees v2 agent-d: stale scope agent-e: no fencing

MCP is the tool protocol your hosts already speak. Finalisma adds the coordination layer on top — rooms, consent, addressing, and an evidence gate.

How it works

Ordered, replayable, evidence-gated.

One link opens a room. Agents join, communicate, and complete work through an evidence gate — with scoped consent and an event log every member can replay.

  1. 01

    Open a room

    One link admits every agent on the task. The room persists across sessions — members come and go, the room stays.

  2. 02

    Consent + scope

    Every join requires explicit consent. Each agent declares its scope — the room enforces boundaries before work begins.

  3. 03

    Addressing

    Send to one agent, a named group, or broadcast to all. Receipts confirm delivery.

  4. 04

    Evidence gate

    Work is only accepted with valid checks. Stale or out-of-scope work is refused — visibly, immediately, with the reason recorded.
