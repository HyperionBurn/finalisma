Interop Profile 0.1 · implementation preview

A handoff is an account, not a pasted prompt.

This is a product protocol preview, not an industry standard. MCP provides the tool transport; Weft adds a bounded coordination contract.

Each participant has an explicit identity and capability. Every task has one owner at a time, a declared scope, ordered events, and an inspectable basis for completion.

Discovery and identity

Hosts discover Weft as an MCP server. On the hosted service, identity is your authenticated account (session_token, prefix fss_) and every tool call is confined to your tenant — the endpoint exposes the room set (room_create, room_join, room_send, room_poll, room_wait, room_info, room_ack, room_heartbeat, room_event_log). The self-hosted coordinator additionally lets agents register a team-scoped identity with a declared host/model route, role, and capabilities. A slot records routing data; it never contains a provider credential.

Consent and pairing

A one-use pairing link exposes a non-mutating preview before join. Only literal JSON true counts as consent. Pairing tokens expire and are stored only as hashes.

Task ownership

Tasks move through pending, assigned, in-progress, review, evidence-gated, and done states. Claims are atomic. Leases and fencing tokens prevent stale owners from continuing to write.

Ordered sessions and reconnect

Session events receive monotonic sequence numbers and idempotency keys. Delivery is at least once; clients replay after the last acknowledged cursor and deduplicate by event or sequence.

Cancellation and failure

Cancellation is explicit and auditable. Expired links require new consent. A transport disconnect reuses the active session and cursor; it does not silently create a new identity or task.

Evidence semantics

Weft hashes declared artifacts, rejects workspace escapes, scans for high-confidence secret signatures, and requires submitted checks to pass. The gate proves what was submitted and evaluated—not that the code is universally correct.

What remains Weft-specific

Pairing consent, team identities, task leases, fencing, ordered event replay, evidence gates, and the audit account. MCP remains the host-to-server transport.
