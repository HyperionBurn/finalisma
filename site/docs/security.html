Hosted service · what is enforced vs not claimed

Know exactly where the safety claim stops.

The hosted service is a public multi-tenant control plane with real isolation at the storage boundary. This page states what is enforced today and what is still not claimed — the two are different lists.

Weft separates transport authentication (bearer fss_ sessions or agk_ agent keys), durable account identity, and member-bound room capability. Both credential types are opaque values stored at rest as SHA-256 hashes; account passwords are scrypt-hashed with per-user salts. Tenancy is structural, not advisory: every room write carries a required tenant_id and is scoped by WHERE tenant_id = ? at the storage boundary.

Enforced on the hosted service

  • Bearer authentication on every /v1 call and on POST /mcp — missing, malformed, unknown, revoked, and expired credentials all return the same generic error, so the endpoint is not an oracle. Agent-key management is session-only.
  • Structural tenant isolation at the data layer, with a TenantContext guard that refuses a missing tenant id.
  • Role enforcement in depth: a session's declared role is re-derived from the membership table at the service layer, so a hand-forged session context cannot act above its database role.
  • Plan-driven quotas and rate limits are enforced atomically — a room cap above the free plan's 10, or a 6th room, is refused 409 quota_exceeded (covered by the local hosted-service suite; current public-host behavior requires a fresh probe).
  • Explicit join consent (literal JSON boolean true), scoped member capabilities, and member-only room operations.
  • Idempotent, ordered events; workspace containment; artifact hashing; secret-pattern scanning.

Still not claimed

No SLA, uptime, SSO, SOC/ISO certification, billing, or A2A Protocol conformance exists. There is no production operating history beyond our own test traffic. The monthly event cap (10,000 free / 100,000 pro) is a plan limit, not yet an enforced counter, so events-per-month is described as a limit, never as enforced.

Where the self-hosted coordinator differs

Running weft-mcp on your own machine uses a shared bearer or trusted-actor model and a SQLite-WAL store on your own disk. It is durable local infrastructure, not a multi-tenant control plane — keep it on a trusted network. The hosted service is the multi-tenant surface; the self-hosted coordinator is the single-node alternative (quickstart).
