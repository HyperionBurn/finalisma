Under one minute · trusted local workspace

Clone to first verified handoff.

A single linear path: start the coordinator, register two agents, pair them with a link, create a task, claim it, submit evidence, complete it. Measured end-to-end on this machine.

Python 3.11+No package installWorkspace-local SQLite

Use a disposable, non-production workspace. Both MCP clients must point at the same Finalisma launcher, workspace root, and state file. The protocol itself runs in under 40 ms; the measured 0.17 s includes Python and SQLite startup.

Measured 2026-08-05

First verified handoff in 0.17 s from a clean temp workspace — MCP stdio server startup, initialize, register × 2, pairing create/preview/join, task create/claim/verify/complete, wall-clock. Human time (reading, copy-pasting, approving the host prompt) is the real budget.

1. Start the coordinator

python -B .\scripts\finalisma-mcp.py --workspace "C:\path\to\shared-workspace" --state "C:\path\to\shared-workspace\.finalisma\state.db"

Leave this running. It opens a stdio MCP server that both agents connect to. For a one-shot proof without hosts: python -B .\scripts\finalisma-smoke.py prints evidence_passed: true.

2. Register Agent A

finalisma_register_agent(team_id="demo", agent_id="agent-a", name="Planner", role="architect", model="gpt-5.6-luna", capabilities=["planning", "research"])

Persist the returned actor_token once in the host's secret storage. Finalisma stores only its SHA-256 hash and will never return the raw token again.

3. Register Agent B

finalisma_register_agent(team_id="demo", agent_id="agent-b", name="Builder", role="coding", model="qwencloud/qwen3.8-max-preview", capabilities=["coding", "testing"])

Persist Agent B's actor_token separately. Stdio defaults to trusted mode so the token is optional for local proofs, but passing it makes the identity boundary explicit.

4. Create a pairing link (Agent A)

finalisma_create_pairing(initiator_id="agent-a", team_id="demo", capabilities_offered=["read", "comment"], actor_token="<agent-a actor token>")

Share the returned join_url or bootstrap_prompt with Agent B. The URL carries the public pairing ID in the path and the one-time token in the #token= fragment — it is a bearer capability.

5. Join with consent (Agent B)

finalisma_pairing_preview(token="<token from #token=>")
finalisma_join_pairing(token="<token from the link>", agent_id="agent-b", model="opencode-go/mimo-v2.5", capabilities=["coding", "testing"], consent=true)

Preview the policy, show it to the user, obtain explicit confirmation, then join. consent must be the JSON boolean true; "false", "yes", and 1 are rejected without consuming the link. Store the returned actor_token and session_token securely — both are returned once.

6. Create a task (Agent A)

finalisma_create_task(team_id="demo", created_by="agent-a", title="Map the API contract", description="Identify endpoints, risks, and tests", scope=["docs/api.md"], preferred_agent="agent-b", idempotency_key="demo-api-map-v1", actor_token="<agent-a actor token>")

The server routes the task and emits a task.dispatch envelope. The idempotency_key makes the call safe to retry.

7. Claim the task (Agent B)

finalisma_claim_task(team_id="demo", agent_id="agent-b", task_id="<task_id>", actor_token="<agent-b actor token>")

Keep the returned fencing_token — you need it for every write to this task. It prevents stale agents from writing after lease loss.

8. Submit evidence (Agent B)

finalisma_verify_task(team_id="demo", agent_id="agent-b", task_id="<task_id>", fencing_token="<fencing_token>", artifact_paths=["docs/api.md"], checks=[{"name": "contract-review", "status": "passed", "evidence": "endpoints mapped, 3 risks identified"}], actor_token="<agent-b actor token>")

The evidence gate hashes the artifact, rejects scope escapes, scans for secret signatures, and blocks completion until every check passes.

9. Complete the task (Agent B)

finalisma_complete_task(team_id="demo", agent_id="agent-b", task_id="<task_id>", fencing_token="<fencing_token>", summary="API contract mapped with 3 findings", actor_token="<agent-b actor token>")

Only an evidence-gated task can be closed. finalisma_team_status shows the final state and audit trail. The handoff is done.

MCP config

Add the server entry to each host's MCP settings. Both clients must point at the same workspace and state file. See examples/mcp.json for the template.

Cleanup

Stop both clients, then remove only the .finalisma directory inside the disposable workspace. No global packages or startup entries are created.

Safety boundary

Do not use production credentials or production incident data. Finalisma coordinates declared work; it does not need a model provider key.
